PREFACE

TEd is a full-screen text files editor for the Picocomputer 6502.
It runs on an 80x30 character terminal with an 8x16 px font.
The maximum document size is 512 lines.

--------------------------------------------------------------------------------
1. INVOCATION
--------------------------------------------------------------------------------

  ted [/sample | /manual | [path]filename] [/view]

  Parameters:
    /view            - open file in read-only view mode (editing disabled)
    /manual          - load TEd manual (also Ctrl+O ROM:manual)
    /sample          - load sample text at startup (also Ctrl+O ROM:sample)
    [path]filename   - file to open at startup (optional)
                     If omitted, a new document named "TEd-NewDocument.txt"
                     is created.

  Examples:
    ted                          new document
    ted MSC0:/notes.txt          open existing file or create new
    ted MSC0:/readme.txt /view   open in read-only view mode
    ted /manual                  open with TEd's manual (this document)
    ted /sample                  open with sample text for testing purposes

--------------------------------------------------------------------------------
2. INTERFACE LAYOUT
--------------------------------------------------------------------------------

  Row  1-2  : Title bar - application name and open filename
  Row  3-28 : Edit area - 26 visible rows of text (scrollable)
  Row 29    : Separator line (marked every 8 columns at standard TAB stops)
  Row 30    : Status bar - status messages, cursor position, mode indicators

  Title bar:
    Left side  - application name and description
    Right side - "!" indicator when document has unsaved changes,
                 then the filename

  Status bar indicators (right side of row 30):

    [VIEW]              Read-only view mode is active. Editing is disabled.
    [INS]|[OVR]         Shows current mode ([INS] as default).
                        INS - new characters shift existing text to the right.
                        OVR - new characters replace existing text in place.
    [A]|[a]             CapsLock state.
    [CLIP]              Clipboard contains data ready to paste.
    Ln N of NN, Col N   Current cursor position.

  The edit area scrolls vertically when the cursor moves outside the
  visible 26-row window.
  "- End of document -" is shown after the last line of text.

--------------------------------------------------------------------------------
3. NAVIGATION
--------------------------------------------------------------------------------

  Key                    Action
  ---------------------  -------------------------------------------------------
  Left / Right           Move cursor one character left / right.
                         At line start / end, wraps to the previous/next line.
  Up / Down              Move cursor one line up / down
  Home                   Move to start of current line (column 1)
  End                    Move to end of text on current line
  Page Up                Scroll up 26 rows
  Page Down              Scroll down 26 rows
  Ctrl+Left / Right      Move cursor one word left / right.
  Ctrl+Shift+Home        Jump to start of document (row 1, column 1)
  Ctrl+Shift+End         Jump to end of document (last row, last column)
  Mouse wheel up         Scroll view up
  Mouse wheel down       Scroll view down

  Arrow keys auto-repeat: a short delay precedes the first repeat, then
  keys fire rapidly. Left/Right without Shift repeat faster than other keys.

--------------------------------------------------------------------------------
4. EDITING
--------------------------------------------------------------------------------

  Key                    Action
  ---------------------  -------------------------------------------------------
  Printable character    Insert character at cursor (INS) or overwrite (OVR)
  Tab                    Insert spaces to the next tab stop 
                         (default every 8 columns)
  Shift+Tab              Remove spaces back to the previous tab stop
  Insert / Alt+I         Toggle between Insert and Overwrite modes
  F4                     Toggle between Edit and View (read-only) mode
  Enter / KP Enter       Split line at cursor; text after cursor becomes a new
                         line below. In list mode: insert next list item.
  Backspace              Delete character before cursor; if at column 1, join
                         current line with the line above
  Delete                 Delete character at cursor; if at end of line, join
                         current line with the line below.
                         If a selection is active, Delete removes the selected
                         text without affecting the clipboard.

  Auto-wrap: when text reaches column 80 while typing, the next character
  continues on a new line. Wrap only occurs when the document has fewer
  than 512 rows.

  All editing keys are disabled in View mode.

  See section 13 for undo / redo operations (F3, Ctrl+Z, Ctrl+Y).

--------------------------------------------------------------------------------
5. SELECTION
--------------------------------------------------------------------------------

  Key                    Action
  ---------------------  -------------------------------------------------------
  Shift+Left / Right     Start or extend a character selection (within a line)
  Shift+Up / Down        Start or extend a line selection
  Shift+Home             Extend character selection to start of line
  Shift+End              Extend character selection to end of line
  Ctrl+Shift+Left        Extend character selection one word to the left
  Ctrl+Shift+Right       Extend character selection one word to the right
  Delete                 Delete selected text (no clipboard copy)

  Selected text is highlighted with a gray background.

  Character selection (Shift+Left/Right/Home/End, Ctrl+Shift+Left/Right):
    Selects a range of characters within a single line, anchored at the
    position where Shift was first pressed.

  Line selection (Shift+Up/Down):
    Selects whole lines, anchored at the line where Shift was first pressed.

  Any cursor movement without Shift cancels the active selection.

  Selection is disabled in View mode.

--------------------------------------------------------------------------------
6. CLIPBOARD (COPY / CUT / PASTE)
--------------------------------------------------------------------------------

  Key                    Action
  ---------------------  -------------------------------------------------------
  Ctrl+C                 Copy selection to clipboard. If no selection is active,
                         copies the current line.
  Ctrl+X                 Cut & Copy then delete the selection (or current line)
  Ctrl+V                 Paste clipboard contents at the current position

  The [CLIP] indicator in the status bar is shown whenever the clipboard
  contains data.

  Character selection copy/cut: copies the selected characters from within
  the line. Paste inserts them inline at the cursor position.

  Line selection copy/cut: copies whole lines. Paste inserts them before the
  current line, and the cursor lands at the end of the last pasted line.

  The clipboard is backed to TMP/ted_cb.dat and TMP/ted_cb.meta so it
  survives across invocations.

  Ctrl+C, Ctrl+X and Ctrl+V are disabled in View mode.

--------------------------------------------------------------------------------
7. FIND AND REPLACE
--------------------------------------------------------------------------------

  Key                    Action
  ---------------------  -------------------------------------------------------
  Ctrl+F                 Open the Find prompt
  Ctrl+H                 Open the Replace prompt

  Find (Ctrl+F):
    1. A "FIND (max 25):" prompt appears. Type the search pattern and press
       Enter. Press Esc to cancel.
    2. The editor searches forward from the current cursor position and
       wraps around to the beginning of the document if needed.
    3. When a match is found the cursor moves to it and the view scrolls
       to place the match near the centre of the edit area.
    4. Press Ctrl+F again (re-enter the same pattern with Enter) to find
       the next occurrence.
    5. If no match exists, "TEXT NOT FOUND" is shown.

  Replace (Ctrl+H):
    Works similarly to Find, but also prompts for a replacement string.
    Each match is highlighted and confirmed individually before replacing.

  Find and Replace are case-sensitive.

8. FILE OPERATIONS
--------------------------------------------------------------------------------

  Key                    Action
  ---------------------  -------------------------------------------------------
  Ctrl+N                 New document - clears the editor and starts a fresh
                         document named "TEd-NewDocument.txt". If the current
                         document has unsaved changes a Save prompt appears.
                         Pressing Esc at the prompt returns to the document.
  Ctrl+O                 Open a file.
  Ctrl+S                 Save the current document.
  Ctrl+Shift+S           Save As - always prompts for a filename.
  Ctrl+W                 Close document.
  Ctrl+Q                 Exit the editor.

  Open (Ctrl+O):
    If the current document has unsaved changes, a prompt appears:
    "Save changes before opening? [Y/N/Esc]"
      Y   - saves the file (prompts for a name if document is new), then opens
      N   - discards changes and continues to open
      Esc - returns to the document without opening
    A "OPEN path/filename :" prompt then appears (max 64 chars).
    Press Enter to confirm, Esc to cancel.
    - If the file exists it is loaded into the editor.
    - If the file does not exist it is created and "FILE CREATED" is shown.
    - On error "cannot open file" is shown.

  Save (Ctrl+S):
    - If the document already has a name, it is saved immediately.
    - If the document is new, a "SAVE path/filename :" prompt appears.
      Press Enter to confirm, Esc to cancel.
    - Trailing spaces and null bytes are stripped from each line.
    - Each line is terminated with a newline character (\n).
    - On success "FILE SAVED" is shown; on error "cannot save file".
    - The title bar updates to reflect the new filename and clears the "!"
      dirty indicator.

  Save As (Ctrl+Shift+S):
    Always shows a "SAVE AS path/filename :" prompt, allowing you to save
    under a different name.

  Exit (Ctrl+Q):
    If the document has unsaved changes, a prompt appears:
    "Save changes before exit? [Y/N/Esc]"
      Y   - saves, then exits
      N   - exits without saving
      Esc - returns to the document

  File paths use a RP6502 filesystem notation, e.g.: MSC0:/documents/notes.txt

--------------------------------------------------------------------------------
9. TEXT FORMATTING
--------------------------------------------------------------------------------

  Key                    Action
  ---------------------  -------------------------------------------------------
  Ctrl+Shift+C           Center the text on the current line
  Ctrl+Shift+R           Right-align the text on the current line
  Ctrl+Shift+L           Remove all leading spaces from the current line

  All three operations work on the line the cursor is currently on.
  Leading spaces are stripped before centering or right-aligning, so the
  operation is idempotent regardless of the current indentation.

  Ctrl+Shift+L moves the cursor left by the number of spaces removed
  (clamped to column 1).

  These keys are disabled in View mode.

10. LISTS
--------------------------------------------------------------------------------

  Key                    Action
  ---------------------  -------------------------------------------------------
  Ctrl+Shift+Alt+L       Activate list mode from the current line's prefix
  Enter                  Insert next list item (in list mode)
  Enter on empty item    Exit list mode, stay on the empty line

  List mode is activated by pressing Ctrl+Shift+Alt+L on a line whose first
  two characters match one of the supported list prefixes:

    Prefix      Mode           Continuation
    ----------  -------------  --------------------------------------------------
    "1." "2."   Numbered       Increments the number; same separator (. or ))
    "a)" "b)"   Alpha          a) b) ...z) aa) ab) ...; same separator
    "* " "- "   Bullet         Repeats the same bullet character
    "> " "= "
    "+ " "# "

  In list mode, pressing Enter splits the line and inserts the next prefix
  at the beginning of the new line, placing the cursor after it.

  Pressing Enter on a line that contains only the prefix (no text after it)
  clears the prefix, exits list mode, and leaves the cursor on that line.

  The status bar shows "LIST: numbered", "LIST: alpha", or "LIST: bullet"
  while list mode is active.

  List mode is disabled in View mode.

--------------------------------------------------------------------------------
11. SPECIAL INSERTIONS
--------------------------------------------------------------------------------

  Key                    Action
  ---------------------  -------------------------------------------------------
  Ctrl+Shift+T           Insert timestamp (date and time) at cursor position
  Ctrl+Shift+P           Insert paragraph (section) sign at cursor position

  Ctrl+Shift+T inserts a 16-character timestamp in the format:
  YYYY-MM-DD HH:MM 
  The timestamp is inserted character by character and respects
  Insert / Overwrite mode. The document is marked as modified.
  The timestamp depends on system RTC.

  Ctrl+Shift+P inserts the ? (paragraph/section) character (CP852 code 0x15)
  at the cursor position, also respecting Insert / Overwrite mode.

  Both keys are disabled in View mode.

13. UNDO / REDO
--------------------------------------------------------------------------------

  Key                    Action
  ---------------------  -------------------------------------------------------
  F3                     Save manual snapshot (undo checkpoint)
  Ctrl+Z                 Undo: restore previous snapshot
  Ctrl+Y                 Redo: restore next snapshot

  F3 saves the current state of the document (all text and cursor position) as
  an undo checkpoint. The status bar shows "SNAPSHOT SAVED".

  Ctrl+Z restores the document to the previous checkpoint. If the document was
  modified since the last checkpoint, the current state is auto-saved first so
  it can be recovered with Ctrl+Y. The status bar shows "UNDO" on success, or
  "NOTHING TO UNDO" if no checkpoints are available.

  Ctrl+Y restores the document to the next (more recent) checkpoint. The status
  bar shows "REDO", or "NOTHING TO REDO" if already at the latest state.

  Snapshots are stored as temporary files (TMP/undo_NNN.tmp, approx. 20 KB
  each) and are not preserved across editor sessions. Up to 255 snapshots are
  kept in a ring; saving a new snapshot (F3 or auto-snapshot on Ctrl+Z)
  discards any future (redo) branch.

  All three keys are disabled in View mode.

--------------------------------------------------------------------------------
14. UTILITIES
--------------------------------------------------------------------------------

  Key                    Action
  ---------------------  -------------------------------------------------------
  F1                     Open keyboard shortcuts reference popup
  F2                     Show ASCII character table popup

  Both stays visible as long as the user hold a key.

  F1 displays a full keyboard shortcuts reference in a popup window listing all
  available key bindings.

  F2 displays the ASCII table as a popup window centered on the screen. It shows
  all 256 character codes arranged in a 16x16 grid with hexadecimal row and
  column labels (in hex format). Control characters that cannot be displayed
  are shown as a dot. 
  

--------------------------------------------------------------------------------
15. LIMITS & XRAM MEMORY USAGE
--------------------------------------------------------------------------------

  Maximum document rows       : 512
  Maximum columns per row     : 80
  Maximum filename length     : 64 characters
  Clipboard capacity          : 32 lines
  Find/Replace pattern length : 25 characters
  Undo snapshots              : 255 (TMP/undo_NNN.tmp, approx. 41 KB each)
  XRAM memory map:
    0x0000 - 0x9FFF   text buffer       512 rows x 80 cols  (40960 bytes)
    0xA000 - 0xE3ED   free                                  (17390 bytes)
    0xE3EE - 0xEDED   clipboard buffer   32 rows x 80 cols  ( 2560 bytes)
    0xEDEE - 0xF60D   screen cache       26 rows x 80 cols  ( 2080 bytes)
    0xF60E - 0xF65F   scratch buffer     file I/O staging   (   82 bytes)
    0xF660 - 0xFFBF   area/window buf    popup save/restore ( 2400 bytes)
    0xFFC0 - 0xFFDF   mouse input        system mouse state (   32 bytes)
    0xFFE0 - 0xFFFF   keyboard input     key bitfield       (   32 bytes)
